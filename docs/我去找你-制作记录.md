## 四、踩到的坑与修复

### 4.1 超长场景导致分镜 JSON 截断

这本书一章只有 3 个场景，但单个场景 1958 字，超过 `chunk_chars=600` 却无法被切开——因为 `chunk_scenes` 只在场景边界切分。

**修复**：新增 `split_scene()`，把超长场景按行拆成多个子场景。修复后 5 块全部成功。

### 4.2 split.py 输出路径不读配置

`--out` 默认写死 `work/scenes.json`，导致切这本书时覆盖了《暗恋那三年》的数据。

**修复**：默认改为 `config.paths.work/scenes.json`。

### 4.3 近景崩成群像拼贴

首次成片 4 个抽样帧里 2 个崩坏（三人拼贴、碎片拼贴），都发生在 `extreme_close` 且 action 是"眼睛/屏幕"这类抽象描述时。

**修复**：`SHOT_TYPES` 里给近景加上强约束：

```python
"close": "close-up, head and shoulders, one person only, no other people in frame"
"extreme_close": "extreme close-up, one single detail, only one face or one hand in frame,
                  no other people, tight framing, shallow depth of field"
```

重抽后两处都变成完整单人画面，拼贴问题消失。

## 六、第二轮修复（四项全做）

按优先级依次修了四个问题，全部在同一次重跑中验证。

### 6.1 年龄感偏小

**问题**：角色卡锁 22 岁，模型仍画出 16–18 岁的脸。

**修复**：
- `age_lock` 改为 `young adult man in his early twenties, 22 years old, university senior, mature adult facial structure, defined jawline, no teenager look, no baby face, no schoolboy appearance`
- 负面词新增 `teenager, adolescent, high school student, childish face, youthful appearance, schoolboy`

**效果**：出图从少年脸变为 22–25 岁成年男性，有法令纹和疲惫感。

### 6.2 背景抽象

**问题**：部分镜头背景变成彩色几何色块，与"城市街道"等设定不符。

**修复**：
- 正向：`setting` 之后强制追加 `detailed environment, realistic architecture, sense of place`
- 负向：新增 `abstract background, colorful abstract shapes, geometric background, pattern background, gradient background, flat backdrop`

**效果**：背景变为具体的木质房间、台灯、书架、天花板灯、窗外绿意。

### 6.3 action 空泛

**问题**：LLM 写 `eyes soft and distant`、`looking at the screen` 这类抽象动作，出图容易空泛或崩成群像。

**修复**：system prompt 新增规则 9/10——

```
9. action 必须是镜头能拍到的具体动作 + 具体道具，禁止只写眼神、表情、心理活动。
   反例：eyes soft and distant / looking at the screen / recalling the past
   正例：his fingertip presses the laptop keyboard, a document with a blinking cursor on screen
10. setting 必须包含具体地点 + 至少一个可见物体 + 一种光源。
   反例：bedroom, night
   正例：university dorm room, wooden desk with stacked books, warm desk lamp, night
```

**效果（97 镜实测）**：
- action 含具体动作：34%
- action 含抽象词：仅 15%
- setting 含光源：59%
- setting 含可见物体：54%

### 6.4 本地 TTS

**原方案**：edge-tts（微软在线，需网络）。

**尝试过的路径**：

| 方案 | 结果 |
|---|---|
| IndexTTS-2 | ❌ Windows 下 pynini / WeTextProcessing 编译依赖过重 |
| ChatTTS | ⚠️ 需 torch，CPU 版国内下载 20+ 分钟未完成，放弃 |
| Windows SAPI | ✅ 可用，但音质是 2000 年代水平 |
| **Piper** | ✅ **最终采用** |

**Piper 配置**：
- 模型：`zh_CN-chaowen-medium.onnx`（63MB，男声）
- G2P 数据：`g2pw.tar.gz` 解压后 108MB
- 依赖：`pip install "piper-tts[zh]" unicode_rbnf`
- 首次运行需从 HF 镜像拉 `bert-base-chinese` 分词器，之后走缓存
- 完全离线、无需 torch、CPU 推理

**接入方式**：`tts.py` 新增 `PiperTTS` 类，`config_wzn.yaml` 的 `tts.engine: piper`。

**实测**：18 句台词全部本地生成，单句 2.74–4.83 秒，成片 81.2 秒。
