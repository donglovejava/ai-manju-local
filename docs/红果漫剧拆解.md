## 二、逐帧分析结论

抽取了第 60–150 秒的帧，以及 76 秒处 0.25 秒间隔的连续帧。

### 2.1 画风：写实 3D/CG，不是 2D 漫画

画面特征：

- 真实皮肤质感（毛孔、泪痕、汗珠、胡须根）
- 金属装甲的磨损、螺丝、划痕、环境反射
- 球鞋的网面、蕾丝、缝线纹理
- 电影级浅景深（前景虚化、主体清晰）
- 湿滑地面的真实反光
- 胶片颗粒感

**这不是"漫画动起来"，这是"用 AI 生成的电影镜头"。**

### 2.2 运动：真视频，不是运镜

对比 76 秒处间隔 0.25 秒的连续帧：

- 背景行人的位置在变化
- 球鞋高光位置在变化
- 画面不是整体缩放/平移，而是**元素各自在动**

→ 确认是**视频生成模型输出**，不是静图 + `zoompan`。

### 2.3 剪辑：1–2 秒一切

1 秒内的帧已经完全不同（球鞋特写 → 地面视角的腿部）。推测平均镜头时长 **1.5–2.5 秒**。

50 秒一集 → 约 **20–30 个镜头**。

### 2.4 声音与字幕

- 中文硬字幕（烧录），白字黑边，位置偏下
- 有配音（未逐句分析，但 B 站版本有音轨）
- 推测有环境音效层（脚步声、雨声、金属碰撞）

## 三、技术栈推断

```
小说《罪名不朽》
   ↓ LLM 改编 / 分集 / 分镜（每集 20–30 镜）
关键帧（写实风格图像模型：Flux / Midjourney / Seedream / 即梦）
   ↓ ★ 图生视频（可灵 / 即梦 / 海螺 / Veo 级别）
3–5 秒写实视频片段
   ↓ 剪辑 + 配音 + 音效 + 字幕
50 秒一集 × 306 集
```

**核心成本在第 3 步**：视频生成。

推算：
- 306 集 × 50 秒 = 4.25 小时 = 15,300 秒成片
- 图生视频按 0.1–0.5 元/秒 → **1,500–7,600 元**（不含重抽）
- AI 视频一次成功率通常 30–50% → 重抽 2–3 倍 → **4,500–23,000 元**
- 加上图像生成、配音、人力（分镜/剪辑/质检，数人月）

**这是一部商业级作品，不是个人作品。** 六季、306 集、967 万播放，背后是团队 + 云算力。

## 四、与本地 8GB 方案的对比

| 维度 | 红果写实漫剧 | 我们的 2D 本地方案 |
|---|---|---|
| 画面风格 | 写实 CG（类电影） | 2D 韩漫/条漫 |
| 镜头运动 | 视频模型生成，元素各自运动 | FFmpeg `zoompan` 整体变换 |
| 单镜时长 | 1.5–2.5 秒 | 2.5–5 秒 |
| 单集镜头数 | 20–30 | 40–70（3 分钟集） |
| 角色一致性 | 模型 + 参考图，较高 | 提示词，约 60% |
| 硬件 | 云 GPU（单机不可能） | RTX 4060 8GB |
| 单集成本 | 数十至数百元 | 电费几分钱 |
| 产能 | 团队 + 云 | 单人 + 本地 |

**结论：这不是同一件事。** 我们做的是"动态漫画"，他们做的是"AI 电影"。技术路线、成本结构、硬件需求全部不同。

## 五、「我怎么能做到这种效果」——四条路

### 路 1：买 API（最快，红果团队的实际做法）

- 可灵 / 即梦 / 海螺的图生视频 API
- 成本：一部 306 集约 5,000–25,000 元
- 优点：质量有保证，无需硬件
- 缺点：依赖服务商，涨价/下线风险

### 路 2：租云 GPU 跑开源视频模型（折中）

- Wan 2.2 14B / HunyuanVideo / LTX-Video
- 租用 RunPod / AutoDL，约 2–3 元/小时
- 一条 4 小时成片约 200–500 小时算力 → **500–1,500 元**
- 缺点：写实度不如闭源，需要自己部署调参

### 路 3：混合（务实）

- 主体用 2D 动态漫（本地，成本≈0）
- 关键镜头（打斗、情绪爆发、转场）用云 API 生成
- 成本可控，观感有亮点
- **推荐给个人创作者**

### 路 4：换赛道（最现实）

- 红果上并非全是写实 CG，也有大量 2D 漫剧
- **都市言情题材用 2D 韩漫风，观感不输写实 CG，且成本低两个数量级**
- 《暗恋那三年》是情感流，特写、眼神、留白比大场面重要——这恰好是 2D 的强项

## 六、给《暗恋那三年》的判断

**不建议追写实 CG 路线**，理由：

1. **算力代差**：8GB 显卡与云视频模型的差距是 1–2 个数量级，不是调参能弥补的
2. **题材错配**：末世/机甲/大场面适合写实 CG；都市暗恋靠的是微表情和氛围，2D 反而更细腻
3. **成本结构**：写实路线单集成本是 2D 的 100–1000 倍，个人无法持续
4. **竞争位**：2D 言情漫剧在红果是供给不足的细分，写实末世是红海

**建议路线**：
1. 先用 2D 韩漫风把第 1 集做出来（当前系统已能产出）
2. 解决角色一致性（角色 LoRA）
3. 数据验证后，再把"高光镜头"用云 API 升级成动态视频
4. 不要一开始就对标头部团队的产品
